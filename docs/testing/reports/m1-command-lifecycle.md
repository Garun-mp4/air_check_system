# M1 — жизненный цикл команд

Реализованы конечные статусы failed/cancelled/expired, сроки ручных и автоматических команд (5/2 минуты), безопасный поздний ACK, отмена противоположного pending-действия, отмена ожидающей части группы и явный повтор только неисполненных целей. PostgreSQL сериализует переходы блокировкой узла. Автоматическое неуспешное действие не повторяется бесконечно. История команд показывает частичное выполнение, причины и доступные действия. Симуляторы проверяют сроки; headless останавливает движение истекшей команды окна.

Проверено:

- Frontend: 348 тестов, 44 файла; typecheck и production build.
- Python: 265 passed, 4 opt-in Compose skipped. Включает реальные PostgreSQL-тесты миграций и очереди, гонку отмены/ACK и новый тест срока в executor.
- Обновление схемы с прежними applied/pending-командами и повторный запуск миграции сохраняют записи.
- Изолированный браузерный стенд с настоящим Better Auth/PostgreSQL: вход тестового владельца, частичный отказ устройства, повтор одной неисполненной цели, отмена группы и запрет анонимного действия.
- Настоящий headless-симулятор получил новую вентиляционную группу, исполнил обе цели и передал принятые ACK.
- Chromium: размеры 1920, 1440, 1024, 768, 390 и 320 px, без горизонтального переполнения; визуально проверены история команд на desktop/mobile. Использован системный `/usr/bin/chromium`: CDN браузеров запрещён сетевой политикой.

Логи и screenshots текущего запуска: `/workspace/.aircheck/m1-*`, `/tmp/m1-vitest.log`, `/tmp/m1-pytest.log`, `/tmp/m1-build.log`. Стенд использует отдельную временную БД; рабочие аккаунты и данные не затронуты. Это локальная проверка, публикация приложения не выполнялась.

Отмена серверной очереди не откатывает уже начавшееся действие устройства; это ограничение явно описано в API. Старые устройства совместимы по ACK; при подключении физической ESP32 нужно добавить проверку срока и синхронизацию часов. Полный Docker Compose E2E остаётся отдельным opt-in набором; проверка M1 выполнена через реальные локальные сервисы и изолированную PostgreSQL.
