# M3 — актуальность измерений и прогнозов

Реализована доказуемая связь прогнозов и рекомендаций с измерением. Результат ML сохраняется для каждой точки; текущая панель не использует прогноз предыдущей точки при отказе ML. Добавлены статусы свежести, связи, отсутствующей модели и ошибки ML. Timeout распространяется на чтение тела ответа. Старые прогнозы сохранены без выдуманных связей.

Проверки: 365 frontend-тестов, 47 PostgreSQL-тестов (включая повторную миграцию существующих прогнозов), typecheck и production build прошли. Python-набор до добавления последнего migration-теста: 270 passed, 4 optional Compose skipped. Реальный браузер с отдельной PostgreSQL и настоящим ML подтвердил успешный прогноз, отказ ML с сохранением новой точки без старого прогноза, восстановление, устаревание данных и потерю связи. Проверены ширины 1440, 768, 390 и 320 px; переполнения нет.

Прогнозы без исходного идентификатора не считаются актуальными. После удаления исходного измерения сохраняется timestamp происхождения. Опциональные тесты полного Compose не запускались.
