# M2 — автоматика с учётом наружного воздуха

Добавлена общая политика оценки наружного PM2.5, температуры и свежести измерений. Окно и вентиляция имеют отдельные разрешения; возможность фильтрованного притока задаётся явно. Подогрев не предполагается. Пороговые состояния гистерезиса сохраняются в PostgreSQL; ограничения по отсутствию свежих данных перепроверяются фоново и при чтении состояния. При холоде/недостоверных данных автоматическое оборудование закрывается/останавливается; ручной override сохраняется. Штатная вентиляция соблюдает минимальную длительность. Старые измерения не инициируют управление поверх более свежих.

Рекомендации используют ту же оценку, что и автоматика. Отключение отображаемых предупреждений не отключает ограничения наружного воздуха. Настройки доступны operator/owner; новый блок формы использует существующие tokens и validation. Миграция `007_outdoor_policy.sql` сохраняет существующие данные.

Проверки:

- Frontend: 359 тестов, 46 файлов, typecheck и production build.
- Python: 269 passed, 4 optional Compose skipped; 45 PostgreSQL-проверок включают сохранение настроек и гистерезиса между независимыми экземплярами репозитория.
- Реальные браузер/API/PostgreSQL: конфликт высокого CO₂/PM2.5, сохранение подтверждённой фильтрации из формы, команды только двум вентиляторам, закрытие притока при холоде, отклонение неверного recovery-порога, устаревание данных.
- Форма проверена на ширинах 1440, 768, 390 и 320 px без горизонтального переполнения; mobile screenshot просмотрен, стандартная рамка fieldset заменена стилями проекта.
- Headless уже содержит сценарии Polluted Outdoor Air и Cold Weather; они сохранены. В legacy simulator добавлен cold_weather, общий Python-набор проверяет допустимые сценарии.

Тестовые исторические данные используют соответствующее им время в fixtures: свежесть больше не зависит от даты запуска тестов. Интеграционные проверки Node используют явное `.ts`-расширение нового runtime-модуля и поддерживаемый `allowImportingTsExtensions` при `noEmit`.

Ограничения: текущий device payload имеет общий timestamp внутренних/наружных данных. Фактическая эффективность фильтра и физический тепловой режим требуют настройки и проверки реальной установки. Полный opt-in Compose набор не выполнялся в M2; проверки проведены через реальные локальные сервисы и изолированную БД.
