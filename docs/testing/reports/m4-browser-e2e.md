# M4 — воспроизводимый браузерный стенд

Добавлен Playwright-набор с настоящими Next/Better Auth, PostgreSQL, ML и headless simulator. На каждом запуске используются новая tmpfs-база, случайные порты и учётные записи, временная модель и секреты. Очистка проверяет уникальную метку контейнера; рабочие volumes не затрагиваются. Добавлены команда запуска, CI, HTML-отчёт, trace и screenshots при ошибке.

Проверки: окончательный расширенный сценарий прошёл дважды на чистых стендах. Подтверждены вход/неверный пароль/cookie/выход, запреты guest/user, разрешения operator/owner, изменение настроек через UI, фактический ACK от симулятора, отмена, истечение, связанный прогноз, отказ ML без старого прогноза, устаревание/отключение, шесть ширин экрана, клавиатура и pointer-raycast выбора объекта в настоящем WebGL. Отсутствующий WebGL не пропускается. После обоих запусков тестовых контейнеров не осталось.

365 frontend-тестов, 271 Python/PostgreSQL-тест, typecheck (включая E2E/config) и production build прошли. Четыре опциональных Compose-теста пропущены. Локально используется системный Chromium; CI устанавливает Chromium и зависимости Playwright. Сам запуск GitHub Actions в облачном окружении не проверялся.

Инструкция: [browser-e2e.md](../browser-e2e.md).
