# Управление и интерфейс

## Камера и сцена

| Клавиша или мышь | Действие |
|---|---|
| W / A / S / D | свободное движение по направлению камеры |
| Q / E | вниз / вверх по мировой вертикали |
| Shift | ускоренное движение |
| Зажатая правая кнопка + мышь | обзор и вращение камеры |
| Колесо | плавный dolly-въезд / отъезд |
| Левая кнопка | выбрать объект; клик по пустому месту снимает выбор |
| F | фокус на выбранном объекте |
| R | стартовое положение камеры |
| C | Visible → Transparent → Hidden для передней стены |
| Esc | отпустить мышь и открыть справку; повторное нажатие возвращает сцену |

Наведение выделяется маркером, выбор — подсветкой объекта. В прозрачном/скрытом cutaway-режиме стена не блокирует raycast.

## Симуляция и локальные команды

| Клавиша | Действие |
|---|---|
| O / K | запрос открытия / закрытия окна через Device Layer |
| I / X | включить / выключить intake и exhaust |
| V | переключить фильтр приточного воздуха |
| Space | пауза / продолжить |
| 1–6 | 1×, 2×, 5×, 10×, 30×, 60× |

Эти сочетания — локальные средства показа стенда; команды backend проходят через ту же механику Device Layer.

## Интерфейс

- Верхняя полоса объединяет паузу и скорость, сценарии, видимость панели устройств и меню инструментов. Статус backend закреплён справа; отдельная кнопка открывает веб-панель AirCheck.
- В меню инструментов находятся подробности backend, отладка среды и справка по управлению.
- Нижняя полоса переключает режимы «Обычный», «Поток», «Датчики», «Проводка» и «Техника»; активный режим выделен цветом.
- HUD слева делает CO₂ главным показателем, рядом показывает PM2.5, температуру и влажность. Ниже расположены наружные условия, фактические состояния окна и вентиляторов, прогноз и стадия демонстрации.
- Правая карточка показывает назначение, интерфейс, узел и живые значения выбранного оборудования. Её можно скрыть кнопкой «Устройства».
- Подробности backend включают доступность API, последнюю телеметрию, выполняемые команды и прогноз, полученный от сервера.
- Отладка меняет входные параметры, заданные в `config/demo.toml`.
- «Автодемо» показывает текущую стадию сквозного сценария и не создаёт команды самостоятельно.

Окружение выполнено в дневной палитре: голубой фон неба, светлая зелёная наружная площадка и нейтральный пол помещения. Элементы интерфейса поглощают клики по своим видимым областям, поэтому нажатие по кнопке не выбирает объект за панелью и не поворачивает камеру.
