# Управление и интерфейс

## Камера и сцена

| Клавиша или мышь | Действие |
|---|---|
| W / A / S / D | свободное движение по направлению камеры |
| Q / E | вниз / вверх по мировой вертикали |
| Shift | ускоренное движение |
| Зажатая правая кнопка + мышь | обзор и вращение камеры |
| Колесо | плавный dolly-въезд / отъезд |
| Левая кнопка | выбрать объект; клик по пустому месту снимает выбор |
| F | фокус на выбранном объекте |
| R | стартовое положение камеры |
| C | Visible → Transparent → Hidden для передней стены |
| Esc | отпустить мышь и открыть справку; повторное нажатие возвращает сцену |

Наведение выделяется маркером, выбор — подсветкой объекта. В прозрачном/скрытом cutaway-режиме стена не блокирует raycast.

## Симуляция и локальные команды

| Клавиша | Действие |
|---|---|
| O / K | запрос открытия / закрытия окна через Device Layer |
| I / X | включить / выключить intake и exhaust |
| V | переключить фильтр приточного воздуха |
| Space | пауза / продолжить |
| 1–6 | 1×, 2×, 5×, 10×, 30×, 60× |

Эти сочетания — локальные средства показа стенда; команды backend проходят через ту же механику Device Layer.

## Интерфейс

- Верхнее меню: SIM, SCENARIOS, VIEW, DEVICES, BACKEND, DASHBOARD, DEBUG, HELP.
- Нижний ряд: Normal, Airflow, Sensors, Wiring, Technical.
- HUD слева показывает CO₂, PM2.5, температуру и RH в комнате и снаружи, окно, вентиляторы, режим времени и прогноз, если backend его вернул.
- Правая панель показывает живое описание выбранного устройства и его текущие значения.
- BACKEND показывает доступность API, время последней принятой телеметрии, число выполняемых команд, прогноз и модель.
- DEBUG меняет входные параметры, заданные в `config/demo.toml`.
- AUTO DEMO отображает текущую стадию сквозного сценария и не создаёт команды самостоятельно.

Элементы UI поглощают клики по своему прямоугольнику, поэтому нажатие по кнопке не выбирает объект за панелью и не поворачивает камеру.
