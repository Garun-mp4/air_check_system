# Протокол цифровой проверки R01

Дата: 11.10.2026. Инструменты: OpenCAD Studio 2026.40.1, build 7d5ee91665b1; схема MCP bb2640277721f23e08cf17085bd9204753f810ece27abf31402be876e2c4683d. Независимый геометрический читатель — cadquery-ocp / OpenCascade; PDF — ReportLab, pypdf, Poppler.

## Выполнено

- Созданы отдельные документы сборки, основания, крышки и чертежей. Документ Start не изменён. INSUNITS=4 (мм).
- Основание и крышка — отдельные 3D solid. Сборка содержит 12 тел с упрощёнными габаритами электроники.
- Добавлены опорные полки SPS30, вырез под его разъём, стойки SCD41 до Z=28, настенные отверстия, пилоты крышки, USB-окно и воздушные окна.
- Основные DWG сохранены через `save_verified`, DWG 2018 / AC1032, `verified:true`, audit без ошибок/предупреждений. DWG чертежей — 1377 сущностей, 4 листа в model space. Подробный ответ сохранения — `cad/save-verification.json`.
- Вид сборки с отведённой крышкой и посадочными местами осмотрен в окне OpenCAD Studio через computer use. `ocs_capture` возвращал ошибку `Unexpected response type`, поэтому автоматический снимок MCP не получен; это ограничение инструмента, не успешная проверка снимка.
- Исходный STL основания с перегородкой экспортирован OpenCAD Studio; удалены 640 треугольников нулевой площади. После обнаружения коллизии 8.96 мм³ с бортиком крышки концы перегородки укорочены до X=7.6 и Y=182.4 в нативном CAD и обменной геометрии. Финальный диалог экспорта недоступен через computer use (`foreground window did not report a process id`); эквивалентные вычитания воспроизведены OpenCascade скриптом `finish_partition_clearance.py`. Печатный STL: 9092 треугольника, объём 310502.25443 мм³; объём нативной модели 310502.25484 мм³. Сетка замкнута, без неманифолдных рёбер и вырожденных граней при сварке вершин с шагом 0.00001 мм. Файл base-raw-R01.stl — исходник до этой коррекции, для печати непригоден.
- STL крышки: 1148 треугольников, 92044.02430 мм³, замкнутый. Поворот на 180° вокруг X и перенос (0,190,68) дают Z=0..6.5 без изменения формы.
- Штатный экспорт STEP из OpenCAD Studio не прочитался OpenCascade: повреждённые ссылки/структура, пустая форма. Нерабочие экспорты исключены из поставки.
- Шесть обменных STEP построены из очищенной поверхности корпуса и документированных REF-габаритов, повторно прочитаны; BRepCheck_Analyzer.IsValid=true. Основание и крышка по одному solid, SPS30 — 1, SCD41 — 2, ESP32 — 7, сборка — 12. Оболочки корпуса замкнуты; разница объёма относительно CAD менее 0.1 мм³.
- Проверка пересечения основания с габаритами: SPS30=0, тело SCD41=0, USB=0 мм³. PCB SCD41≈1.6 и PCB ESP32≈2.808 мм³: намеренное перекрытие краёв защёлками на 0.1 мм, не случайная коллизия. Упругая работоспособность требует пробной печати. Полный допусковый анализ реальных плат не выполнялся.
- Пересечение финального основания с крышкой = 0 мм³. Номинальный зазор от концов перегородки до внутренней грани бортика 0.3 мм; толщина бортика 3 мм. Эти размеры согласованы на листах и в РЭ.
- Сечения А-А и Б-Б извлечены из проверенной поверхности 3D-модели через OpenCascade. А-А включает опоры SPS30, стойки крышки и пилотные отверстия; штриховка обрезана по материалу и исключает полости. Источник — `drawings/model-sections.json`.
- Финальные PDF сгенерированы из того же источника сущностей, что DWG; шрифт встроен. Проверены число/форматы страниц и извлекаемый текст, листы растеризованы Poppler и визуально просмотрены. CAD-плоттер терял часть текста, поэтому финальные PDF выпущены через ReportLab.

При заключительной проверке исправлены все основные надписи: текст размещён внутри ячеек с полями, колонка должностей расширена для отображения Standard в CAD, вертикальные размеры повёрнуты и вынесены из контуров, подпись В-В отделена от штриховки. Проверены все 193 текста: пересечений текст–текст и текст–линия нет по консервативным габаритам шрифта; минимальный отступ внутри проверяемых ячеек 0.4 мм. Штамп дополнительно осмотрен непосредственно в OpenCAD Studio. Проверка охватывает текущее отображение и PDF, не гарантирует одинаковые метрики при подмене шрифтов в сторонней CAD.

Машиночитаемые результаты: `manufacturing/stl-inspection.json`, `step-inspection.json`, `clearance-inspection.json`, `documentation/pdf-inspection.json`, `drawings/layout-inspection.json`. Скрипты воспроизводимы, пути основаны на расположении файла. Для проверки STEP необходим пакет cadquery-ocp; он использован в отдельном временном окружении, в основной проект зависимость не добавлялась.

## Не выполнено / критерии завершения после закупки

Печать, примерка, измерения реальных деталей, слайсинг на конкретном принтере, ресурс защёлок, нагрев, CO2/PM-сравнение, радиосвязь и аппаратная интеграция не выполнялись. Полный нормоконтроль и подписи отсутствуют. Перегородка и уменьшенный отсек SCD41 выполнены в CAD; их тепловая эффективность требует измерения.

Цифровой выпуск R01 завершён. Часть 1 в исходном понимании с физически подтверждёнными посадками и метрологической проверкой остаётся открытой до изготовления образца и выполнения протокола РЭ. Ни отсутствие купленных деталей, ни положительный audit DWG не заменяют эти проверки.
