# Итоговый комплект физической части AirCheck

**Актуальность комплекта: 12.10.2026.** В папке сведены цифровые выпуски всех трёх узлов: AC-01 R02, AC-02 R04, AC-03 R02. Чертежи, документация, нативные CAD, STEP-сборки, STEP деталей и STL обновлены из проверенных исходных каталогов.

В папках узлов сохранены отдельные исторические редакции и ранние неверсированные файлы для трассируемости. Для изготовления использовать только версии, указанные в таблице ниже и в README соответствующего узла; старые PDF/STEP/DWG не подменяют текущий выпуск.

## Статус готовности

- Выпущены 9 STL в миллиметровых номинальных размерах и соответствующие STEP печатных деталей. STL не содержат метаданных единиц: в слайсере выбирать мм и масштаб 100%.
- STL не корректировались под усадку конкретного принтера. Ориентацию см. в README соответствующего узла. G-code не выпускался: принтер и материал не выбраны.
- STEP-файлы независимо проверены на повторное чтение и корректность твёрдых тел. Проверки сеток, габаритов и пересечений записаны в `manufacturing/model-inspection-*.json`.
- AC-02 имеет отдельную полную нативную 3D-сборку OpenCAD Studio R04. STEP содержит точные заводские модели SPS30 и SHT45; электронные объекты не являются печатными деталями.
- Предыдущие чертежи, CAD-версии и исходные материалы сохранены для трассируемости; устаревшие и диагностические STL из итоговой папки исключены. **Для печати использовать только 9 STL с суффиксами R02/R04, перечисленные в README узлов.** Дефектный `AC-01-001-base-raw-R01.stl` оставлен лишь в рабочем исходном каталоге и в итоговый комплект не входит.

## Что осталось после цифрового выпуска

Компоненты ещё не куплены. Физическая посадка, поведение защёлок, фактический воздухообмен и точность измерений после сборки не подтверждены. Требуются контрольная печать и сборка на выбранном принтере с реальными компонентами, а также согласование применяемых ГОСТ и оформление нормоконтроля. Для AC-02 сохраняется исходное условие установки под навесом; IP и климатическая квалификация не заявлены. В отчётах отмечены небольшие цифровые контакты SPS30 с направляющими AC-01 (5,9152 мм³) и основания AC-02 (0,00212 мм³); габарит корпуса не подгонялся скрытыми поправками.

`manifest-sha256.json` в корне комплекта содержит контрольные суммы его файлов, кроме самого манифеста. В каждом узле также обновлена собственная ведомость.
