# Долгосрочная история

Сырые данные сохраняют прежний срок (24 ч по умолчанию). При очистке истекающие точки в той же транзакции добавляются к почасовым агрегатам; только затем удаляются. Повторная очистка не добавляет уже удалённые точки повторно. Для текущих сырых данных пересчитывается отдельный live snapshot; архив и live объединяются по часу/источнику. Это сохраняет статистику при очистке части часа. Архив хранится 90 суток, чтобы сравнивать месяц с предыдущим месяцем; месяц читается из индексированных агрегатов и ограниченного текущего raw-окна.

Средние взвешены числом измерений. Сохраняются суммы, min/max семи показателей, число точек и покрытие. Значение считается наблюдённым до следующей точки, максимум 90 секунд; длительные пробелы не интерполируются. Последняя точка без следующего измерения не добавляет длительность: время после неё неизвестно. Пересчёт при неизменных данных стабилен. Интервалы через границу часа/суток разделяются. Открытие окна берётся из измерения; работа вентиляции — из свежего фактического состояния при приёме, иначе неизвестна.

Пороги CO₂/PM2.5 фиксируются на измерении при приёме. Изменение настроек не пересчитывает прошлые превышения. Старые точки без снимка порога имеют неизвестную длительность превышений, а не подтверждённый ноль. API выдаёт отдельно время известного порога и оборудования. Поздние точки в доступном raw-окне включаются при следующем пересчёте. Точки раньше сохранённого watermark отклоняются с 422; архив уже финализирован. Приём и очистка используют общую транзакционную блокировку. Удалённая ранее история не восстанавливается.

`GET /api/v1/history?days=7|30&source=all|real|simulator|unknown&timezone=UTC`: нужен вошедший пользователь любой роли. Возвращаются from/to, часовые строки, summary и previous_summary. В summary имеются samples, metrics (average/min/max) и totals (длительности в секундах). При выборе all значения суммируют выбранные потоки; для оценки покрытия одного помещения выбирайте отдельный источник.

Часы группируются в UTC независимо от настроек браузера. Текущий период начинается на границе UTC-часа; конец — время запроса. Сравнение использует непосредственно предшествующий период той же длины. График показывает средний CO₂ по UTC-дням, а сводка позволяет выбрать каждый показатель. Отсутствие данных и неполное покрытие видны явно.

`format=csv` выгружает те же строки: UTC-идентификатор часа, локальное время в выбранной валидной timezone (например Europe/Moscow), имя зоны, источник, единицы и агрегаты. UTC-идентификатор различает повторяющиеся локальные часы при DST. Экспорт ограничен 30 днями и максимум 2160 строками (720 часов × 3 источника); произвольные диапазоны не принимаются. Реквизиты/сессии в CSV отсутствуют. Для старых неизвестных показателей используются пустые значения; coverage/known seconds нужны для интерпретации нулевых длительностей.

При очистке частичного часа интервал удаляемой точки обрезается точно на watermark. Для текущего окна сохраняется последняя граничная точка как carry без увеличения числа измерений/сумм. Её интервал пересчитывается с поздними live-точками и ограничен исходными 90 секундами; это предотвращает пересечение архивного и текущего покрытия. При следующей очистке carry переносится в архив и удаляется/обновляется. Последняя точка без известного следующего наблюдения не продлевает покрытие.
