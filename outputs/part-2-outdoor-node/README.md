**Документы:** R04, цифровой прототип, 11.10.2026. **Геометрия модели:** R01, без изменений.

**Установка по исходным данным:** под навесом, без прямого солнца и осадков
**Состояние электроники и принтера:** не куплены / не выбраны

## Референсная комплектация

ESP32-DevKitC-32E V4 с ESP32-WROOM-32E, Sensirion SPS30 по UART и плата Adafruit SHT45 #5665 **без PTFE** по I²C. Компоненты не закуплены; перед печатью сверить артикул и ревизию реальных устройств. В полной STEP-сборке SPS30 и плата Adafruit представлены геометрией из файлов изготовителей; ESP32 — упрощённой габаритной моделью LOD0. Все электронные объекты служат только для проверки компоновки и не являются печатными деталями.

## Ограничения выпуска

Это цифровой выпуск для проверки компоновки и изготовления пробного комплекта. Модель принтера, пластик, анкеры, длина кабелей и фактические партии компонентов ещё не известны. Посадки, ветровая нагрузка, ресурс пластика, конденсация, воздействие дождя/пыли/UV и точность измерений после установки физически не испытывались. Степень IP и климатическое исполнение не присваиваются.

По данным Sensirion, для SPS30 рекомендованы 10–40 °C и 20–80 % RH; эксплуатация за пределами этих условий не подтверждается этим проектом даже при установке под навесом. Если фактическая площадка выходит за рекомендуемые условия или подвергается косому дождю/конденсату, нужна переработка и отдельная проверка. До неё узел использовать как лабораторный/площадочный прототип в контролируемых условиях.

Материал R01 не закреплён: ASA — кандидат для дальнейшего испытания на подходящем принтере; PETG допустим для пробной сборки под навесом. Перед серийной печатью проверить поле не меньше 176 × 190 × 90 мм, ориентацию, поддержки и настройки слайсера.

Подписи и утверждение основной надписи оставлены для нормоконтроля. Комплект оформлен с учётом выбранных документов ЕСКД, но не является подписанной и утверждённой рабочей конструкторской документацией.
