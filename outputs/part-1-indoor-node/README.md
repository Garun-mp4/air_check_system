# AirCheck — часть 1: внутренний измерительный узел

**Чертежи и документация R02. 3D-выпуск — R02 от 12.10.2026; номинальная геометрия корпуса сохранена относительно R01, поскольку изменения R02 касались оформления.**

Корпус 150 × 190 × 68 мм для ESP32-DevKitC-32E V4, Adafruit SCD-41 #5190 и Sensirion SPS30. Детали ещё не куплены. Назначены исходные условия: сухое помещение, настенный монтаж, FDM/PETG, сопло 0.4 мм. Части 2 и 3 также выпущены отдельными цифровыми комплектами: [наружный узел AC-02 R04](../part-2-outdoor-node/README.md) и [узел управления AC-03 R02](../part-3-controller-node/README.md). Физическая приёмка всех трёх узлов остаётся открытой.

## Перед изготовлением

1. Покупать указанные платы и ревизии; аналоги имеют другие размеры. Сверить размеры и разъёмы до полной печати.
2. Проверить рабочее поле принтера: требуется не менее 160 × 200 × 70 мм с учётом небольшого brim; реальные запретные зоны принтера проверяются отдельно.
3. Сначала напечатать образец пилотного отверстия и защёлки; STL подготовлены без масштабирования и компенсации конкретного принтера.
4. Напечатать основание дном вниз, крышку наружной стороной вниз. В слайсере проверить локальные поддержки, особенно защёлок и горизонтальных окон.
5. Выполнить физическую приёмку из РЭ: посадки, USB-кабель, разделение потоков SPS30 и нагрев SCD41.

**Границы готовности:** цифровые файлы выпущены и проверены. Реальная посадка, долговечность защёлок, точность датчиков в корпусе, печать на конкретном принтере и нормоконтроль кафедры не подтверждены. Корпус не имеет заявленного IP. Прошивка ESP32 и интеграция физических узлов в API в эту часть не входят.

DWG — основной редактируемый геометрический исходник. STEP печатных корпусов содержит проверенные фасетные BREP-поверхности; STEP сборки дополнительно содержит заводскую геометрию SPS30 без масштабирования. SCD41 и ESP32 в сборке представлены помеченными LOD0-габаритами. Отчёт фиксирует посадку SPS30 и намеренное зацепление краёв SCD41/ESP32 защёлками на 0,1 мм; фактические платы и упругость защёлок требуют проверки тестовой печатью. Размеры корпуса не менялись.

Чертежи оформлены с учётом выбранных правил ЕСКД; это не подписанный и не утверждённый комплект предприятия. Обозначения AC-01 условные проектные. В R02 исправлено центрирование табличных надписей, а исходный выпуск R01 сохранён как архивный без перезаписи. Для воспроизведения R02 PDF: `drawings/build_drawing_source.py`, затем `documentation/build_pdf.py`. Для STL/STEP см. скрипты и JSON в `manufacturing`.

R02 STEP-сборка и ведомость проверки воспроизводятся через `manufacturing/build_model_release_R02.py`; он повторно открывает экспортированные STEP, проверяет сетки STL и пересечения корпуса с электроникой. Исходный `base-raw-R01.stl` относится к состоянию до подрезки и содержит дефекты экспорта — не использовать для печати. Для обновления сечений перед PDF выполнить `drawings/extract_sections.py`; для проверки оформления — `drawings/check_layout.py`.
