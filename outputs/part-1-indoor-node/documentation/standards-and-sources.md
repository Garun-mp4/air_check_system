Карточки действующих стандартов и планы замены сверены при выполнении части 1. Новые редакции ряда ГОСТ Р 2.xxx-2026 вводятся 01.10.2027 с правом досрочного применения; выпуск R01 не смешивает их с перечисленными редакциями. Для линий действующий ГОСТ 2.303-68 проверялся по [реестру Росстандарта](https://protect.gost.ru/gost?month=0&page=5&search=&year=0). Ошибки/неполнота метаданных ГОСТ Р 2.052-2024, выявленные в части 0, не устранены; он не указан как подтверждённо применённый.

ГОСТ 2.701/2.702 не заявлены выполненными: функциональная схема и монтажная таблица не являются полной Э3. ГОСТ 14254 не используется для присвоения IP, испытаний нет. Климатическое исполнение по ГОСТ 15150 не присваивается. Требуется нормоконтроль кафедры: обозначения, формы СП/основной надписи, подписи, требования к электронной модели. Указанная матрица — прозрачное описание применённых правил и оставшихся формальностей, не свидетельство полного соответствия ГОСТ.

Габаритные REF-модели не называются точными моделями производителей. У ESP32 упрощённые модуль и штыри частично перекрываются между собой; это консервативные зоны резервирования места. Суммарный объём сборки не является массой устройства. Нельзя использовать эти REF для изготовления электроники.

## 3. Сохранённые исходники и права

Файлы в `cad/reference` получены из указанных первичных источников 11.10.2026. SHA256 всех поставляемых файлов записаны в `manifest-sha256.json`. Для Adafruit сохранён исходный текст лицензии `adafruit_scd4x_license.txt`; соблюдать его при производных работах. Файлы Espressif и Sensirion сохранены как технические справочные материалы с указанием происхождения; открытая лицензия на свободное переиздание/коммерческое использование не предполагается. При публикации за пределами учебного репозитория проверить условия правообладателей.

Шрифт GOST Type BU установлен локально в Windows; исходный TTF в репозиторий не копируется. PDF содержит необходимое подмножество шрифта. Перед публичным распространением проверить права на установленный шрифт.
